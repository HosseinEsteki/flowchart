# فلو‌کرفت (FlowCraft) 🎨⚡
### استودیوی مدرن و مشارکتی طراحی فلوچارت، دیاگرام‌های سیستمی و معماری نرم‌افزار

---

## 📖 معرفی پروژه (Overview)

**فلو‌کرفت (FlowCraft)** یک پلتفرم جامع، مدرن و تحت وب برای رسم انواع فلوچارت‌ها، نمودارهای جریان داده (DFD)، دیاگرام‌های فرآیندی و فرآیندهای تجاری (BPMN) است. این پلتفرم با رابط کاربری دوزبانه (فارسی راست‌چین و انگلیسی)، پشتیبانی از چند صفحه در هر پروژه، خروجی‌های پیشرفته گراف تعاملی و پرینت، تاریخچه نسخه‌ها و مدیریت پروژه‌ها طراحی شده است.

---

## ✨ ویژگی‌های کلیدی (Key Features)

### ۱. ⚙️ پنل تنظیمات و اطلاعات پروژه (Project Settings & Metadata)
- **ویرایش مشخصات اصلی:** ویرایش نام پروژه (Title) و شرح و مستندات کلی پروژه (Project Description) مستقیماً از نوار کناری.
- **ذخیره‌سازی هوشمند:** ذخیره خودکار هنگام خروج از فیلد (onBlur) و دکمه ذخیره دستی به همراه اعلان وضعیت.
- **آمار زنده دیاگرام:** نمایش لحظه‌ای تعداد صفحات، تعداد کل گره‌ها (Nodes)، تعداد کل پیوندها (Edges) و نسخه‌های پشتیبان.
- **شناسه پروژه و اشتراک‌گذاری:** دسترسی سریع به شناسه پروژه (Project ID) جهت فراخوانی و اشتراک‌گذاری.

### ۲. 📄 مدیریت چند صفحه‌ای (Multi-Page Flowcharts)
- امکان افزودن بی‌نهایت صفحه مستقل در هر پروژه فلوچارت.
- نوار تب‌های اختصاصی در پایین صفحه مشابه ابزارهای مطرح (Figma / Miro / Draw.io).
- تغییر نام صفحات با دوبار کلیک یا منو.
- تکثیر صفحه (Duplicate) به‌همراه تمام اشکال و اتصالات.
- حذف صفحه با تأییدیه امنیتی.
- شمارنده زنده گره‌ها و اتصالات برای هر صفحه به‌صورت مجزا.

### ۳. 📁 داشبورد مدیریت پروژه‌ها (My Projects Dashboard)
- داشبورد جامع **پروژه‌های من** با امکان جستجوی زنده در نام و متادیتا.
- ایجاد پروژه فلوچارت جدید (بوم خالی یا بر اساس الگوها و قالب‌های آماده).
- تکثیر، تغییر نام، حذف امن و پیش‌نمایش اطلاعات هر پروژه.
- ورودی و خروجی پروژه به‌صورت فایل JSON جهت پشتیبان‌گیری و انتقال آسان.

### ۴. 🔷 اشکال استاندارد فلوچارت (Standard Shapes)
- **شروع / پایان (Terminal):** کپسولی با حاشیه نرم.
- **فرآیند (Process):** مستطیل پردازشی داده‌ها و عملیات‌ها.
- **تصمیم‌گیری (Decision):** لوزی ارزیابی شروط منطقی.
- **دریافت ورودی / خروجی (Input/Output):** متوازی‌الاضلاع استاندارد I/O.
- **سند / گزارش (Document):** شکل سند با لبه موجی.
- **زیربرنامه (Subroutine):** فرآیند از پیش تعریف‌شده با خطوط جانبی.
- **پایگاه داده (Database):** استوانه ذخیره‌سازی اطلاعات.
- **کانکتور (Connector):** دایره ارجاع بین مراحل.
- **یادداشت توضیحی (Note):** برچسب متنی برای مستندسازی بصری.

- **پشتیبانی کامل از متن‌های چندخطی (Multi-line Text):** امکان درج چندین خط متن با کلید `Enter`، تراز و مرکزچینی عمودی هوشمند و افزایش خودکار ارتفاع شکل جهت نمایش شکیل متن‌های طولانی.

### ۵. 🔀 اتصالات و خطوط هوشمند (Smart Connectors)
- اتصال هوشمند پورت‌های چهارگانه گره‌ها (Top, Right, Bottom, Left).
- سه سبک رسم خط: **شکسته ارتوگونال (Orthogonal/Stepped)**، **منحنی نرم (Bézier Curve)** و **مستقیم (Straight)**.
- امکان ثبت برچسب متنی روی هر خط اتصال (مثلاً «بله»، «خیر»، شروط تصمیم‌گیری).
- استایل‌های خط ممتد، خط‌چین و فلش‌های دوطرفه با امکان تغییر رنگ و ضخامت.

### ۶. 🌐 خروجی تعاملی و آفلاین Vis-Network (Interactive Network Graph)
- **پکیج آفلاین ZIP (کاملاً محلی بدون اینترنت):**
  - تولید یک فایل ZIP کامل شامل `index.html` به‌همراه پوشه اختصاصی `assets` (کتابخانه محلی Vis-Network JS و CSS).
  - بدون هیچ‌گونه نیاز به CDN یا اتصال به اینترنت، مناسب برای شبکه‌های امن و سازمان‌ها.
- **فایل تک‌صفحه‌ای وب مستقل (.HTML):**
  - خروجی دیاگرام در قالب یک فایل HTML تعاملی سبک برای اشتراک‌گذاری سریع.
- **قابلیت‌های نمایشگر هوشمند:**
  - موتور فیزیک شبکه‌ای و شبیه‌ساز گرانشی (Physics Simulation).
  - قابلیت سوئیچ بین صفحات مختلف پروژه.
  - نمایش جدول ساختاریافته گره‌ها و اتصالات به‌همراه یادداشت‌های پروژه.
  - نوار جستجو و فیلتر بر اساس نام یا نوع گره.

### ۷. 🖨️ خروجی پرینت اختصاصی و بهینه‌سازی چاپ (Print Studio)
- **حالت‌های رنگی چاپ:**
  - **رنگی کامل (Original Color):** حفظ تمام رنگ‌ها و استایل‌ها برای کاتالوگ و چاپگر رنگی.
  - **خاکستری دقیق (Grayscale):** تبدیل ریاضی طیف رنگ‌ها به کنتراست بالای خاکستری مناسب پرینترهای لیزری.
  - **خطی کم‌مصرف (Line-Art / Ink Saver):** حذف کامل پس‌زمینه‌ها برای صرفه‌جویی چشم‌گیر در مصرف کارتریج و جوهر.
- **تنظیمات قلم و تایپوگرافی:**
  - انتخاب قلم: **وزیرمتن (Vazirmatn)**، **ایران‌سنس / یکان سیستمی**، **شبنم (Shabnam)**، **سنس مدرن (Sans-serif)** یا **سریف رسمی (Serif)**.
  - تنظیم اندازه فونت توضیحات (۱۰ تا ۱۸ پیکسل) و عنوان صفحه (۱۶ تا ۲۸ پیکسل).
  - وزن قلم و تراز متن (راست‌چین، وسط‌چین، چپ‌چین، تراز دوطرفه Justify).
- **تنظیمات صفحه و کاغذ:**
  - اندازه‌های استاندارد: **A4**، **A3**، **Letter**، **Legal**.
  - جهت صفحه: **افقی (Landscape)** یا **عمودی (Portrait)**.
  - کادر و قاب خطی دور نمودار، تنظیم حاشیه، درج تاریخ و شماره‌گذاری صفحات.
  - جایابی توضیحات: زیر نمودار، بالای نمودار یا به صورت صفحه ضمیمه مجزا (Appendix).

### ۸. 📤 پنجره خروجی یکپارچه و چندگانه (Unified Export Modal)
تمامی گزینه‌های خروجی با ساختار بصری کاملاً منظم، هم‌شکل و استاندارد در دسترس هستند:
- **پکیج آفلاین Vis-Network (ZIP):** پکیج وب با دارایی‌های محلی آفلاین.
- **فایل وب مستقل Vis-Network (HTML):** صفحه وب مستقل تعاملی.
- **تصویر PNG:** تصویر با کیفیت بالا و شفافیت پس‌زمینه.
- **برداری SVG:** فایل وکتوری مقیاس‌پذیر بدون افت کیفیت.
- **سند چندصفحه‌ای PDF:** فایل PDF رسمی با سربرگ و متادیتا.
- **آماده‌سازی پرینت (PRINT):** ورود به استودیوی چاپ و تنظیمات پرینت.
- **نسخه پشتیبان JSON:** خروجی کامل ساختار داده‌ها برای بایگانی و جابجایی.

### ۹. 🕒 تاریخچه و مدیریت نسخه‌ها (Version Control & Snapshots)
- ثبت اسنپ‌شات‌های نام‌گذاری‌شده از وضعیت پروژه در هر لحظه.
- بازگردانی (Restore) پروژه به وضعیت هر نسخه با یک کلیک.
- پشتیبان‌گیری خودکار از تغییرات قبل از بازگردانی نسخه‌های قدیمی.

### ۱۰. 🎨 شخصی‌سازی و تم‌های رنگی (Color Themes)
- پالت‌های رنگی جذاب و چشم‌نواز: **روشن مدرن (Modern Light)**، **دارک مود نئونی (Neon Dark)**، **شفق قطبی (Aurora)** و **غروب پاستلی (Sunset)**.
- حالت‌های شبکه پس‌زمینه (نقطه‌ای، شبکه‌ای، بدون شبکه).
- قابلیت چسبیدن به شبکه (Snap to Grid) و نقشه کوچک کمکی (Minimap Radar).
- پشتیبانی کامل از کلیدهای میانبر استاندارد.

## 🛠️ فناوری‌های مورد استفاده (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons
- **Interactive Graph Engine:** Vis-Network (Bundled Local & Offline)
- **Archive Packager:** JSZip
- **Build Tool:** Vite
- **Backend & API:** Node.js, Express, WebSocket (`ws`)
- **Canvas Rendering:** Pure SVG & Vector Math (طراحی روان بر پایه ریاضیات برداری)
- **Storage:** Disk JSON persistence + Browser LocalStorage fallback

## 🚀 راهنمای نصب و راه‌اندازی (Getting Started)

### پیش‌نیازها
- **Node.js** نسخه 18 یا بالاتر
- **npm** یا **pnpm** یا **yarn**

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای پروژه در محیط توسعه (Dev Mode)
```bash
npm run dev
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:3000` بروید.

### بیلد پروژه برای پروداکشن (Production Build)
```bash
npm run build
```

### اجرای نسخه پروداکشن
```bash
npm start
```
