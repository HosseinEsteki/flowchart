# فلو‌کرفت (FlowCraft) 🎨⚡
### استودیوی مدرن و مشارکتی طراحی فلوچارت، دیاگرام‌های سیستمی و معماری نرم‌افزار

---

## 📖 معرفی پروژه (Overview)

**فلو‌کرفت (FlowCraft)** یک پلتفرم پیشرفته، روان و تحت وب برای رسم انواع فلوچارت‌ها، نمودارهای جریان داده (DFD)، دیاگرام‌های فرآیندی و فرآیندهای تجاری (BPMN) است. این برنامه با رابط کاربری دوزبانه (فارسی راست‌چین و انگلیسی)، پشتیبانی از چند صفحه در هر پروژه، داشبورد مدیریت چندین پروژه، همکاری همزمان تیمی و ذخیره‌سازی چندلایه طراحی شده است.

---

## ✨ ویژگی‌های کلیدی (Key Features)

### ۱. 📄 مدیریت چند صفحه‌ای (Multi-Page Diagrams)
- امکان افزودن بی‌نهایت صفحه مستقل در هر پروژه فلوچارت.
- نوار تب‌های اختصاصی در پایین صفحه مشابه ابزارهای مطرح (Figma / Miro / Draw.io).
- تغییر نام صفحات (با دوبار کلیک یا منو).
- تکثیر صفحه (Duplicate) به‌همراه تمام اشکال و اتصالات.
- حذف صفحه با تایید امنیتی.
- شمارنده گره‌ها و اتصالات برای هر صفحه به‌صورت مجزا.

### ۲. 📁 مدیریت پروژه‌ها (My Projects Dashboard)
- داشبورد جامع **پروژه‌های من** با امکان جستجوی زنده.
- ایجاد پروژه فلوچارت جدید (بوم خالی یا بر اساس قالب‌های آماده).
- تکثیر، تغییر نام، حذف امن و پیش‌نمایش متادیتای هر پروژه.
- ورودی و خروجی پروژه به‌صورت فایل JSON جهت پشتیبان‌گیری و جابجایی آسان.

### ۳. 🔷 اشکال استاندارد فلوچارت (Standard Shapes)
- **شروع / پایان (Terminal):** کپسولی با حاشیه نرم.
- **فرآیند (Process):** مستطیل پردازشی داده‌ها و عملیات‌ها.
- **تصمیم‌گیری (Decision):** لوزی ارزیابی شروط منطقی.
- **دریافت ورودی / خروجی (Input/Output):** متوازی‌الاضلاع I/O.
- **سند / گزارش (Document):** شکل سند با لبه موجی.
- **زیربرنامه (Subroutine):** فرآیند از پیش تعریف‌شده با خطوط جانبی.
- **پایگاه داده (Database):** استوانه ذخیره‌سازی اطلاعات.
- **کانکتور (Connector):** دایره ارجاع بین مراحل.
- **یادداشت توضیحی (Note):** برچسب متنی برای مستندسازی.

### ۴. 🔀 اتصالات و خطوط هوشمند (Smart Connectors)
- اتصال هوشمند پورت‌های چهارگانه گره‌ها (Top, Right, Bottom, Left).
- سه سبک رسم خط: **شکسته (Orthogonal/Stepped)**، **منحنی نرم (Bézier Curve)** و **مستقیم (Straight)**.
- امکان ثبت برچسب متنی روی هر خط اتصال (مثلاً «بله»، «خیر»، شروط).
- استایل‌های خط ممتد، خط‌چین و فلش‌های دوطرفه.

### ۵. 👥 همکاری همزمان تیمی (Real-Time Live Collaboration)
- مبتنی بر WebSockets با قابلیت اتصال چندین عضو همزمان.
- نشانگر ماوس زنده با نام و رنگ اختصاصی هر همکار.
- همگام‌سازی بلادرنگ تغییرات گره‌ها و خطوط روی صفحات.
- چت اختصاصی درون‌برنامه‌ای برای تبادل نظر اعضای تیم.

### ۶. 🕒 تاریخچه و مدیریت نسخه‌ها (Version Control & Snapshots)
- ثبت اسنپ‌شات‌های نام‌گذاری‌شده از پروژه در هر لحظه.
- بازگردانی (Restore) پروژه به وضعیت هر نسخه با یک کلیک.
- پشتیبان‌گیری خودکار از تغییرات قبل از بازگردانی.

### ۷. 💾 ذخیره‌سازی ابری و آفلاین چندلایه (Dual Persistence)
- ذخیره‌سازی خودکار در پایگاه‌داده سرور (`/api/projects`).
- کش بلادرنگ در مرورگر (`localStorage`) جهت تضمین عدم از دست رفتن اطلاعات در نوسانات شبکه.

### ۸. 📤 خروجی‌های حرفه‌ای (Multi-Format Export)
- **تصویر PNG:** تصویر با کیفیت بالا و شفافیت پس‌زمینه.
- **برداری SVG:** فایل برداری مقیاس‌پذیر و مناسب برای مستندات و چاپ.
- **سند PDF:** فایل PDF رسمی با سربرگ و عنوان پروژه.
- **صفحه وب مستقل تعاملی (HTML):** فایل HTML کاملاً مستقل و قابل باز شدن در هر مرورگری بدون نیاز به نصب نرم‌افزار.
- **فایل JSON:** خروجی خام ساختار داده‌ها برای بایگانی و ایمپورت مجدد.

### ۹. 🎨 شخصی‌سازی و تم‌ها (Themes & UI)
- تم‌های رنگی استاندارد: **روشن مدرن (Modern Light)**، **دارک مود نئونی (Neon Dark)**، **شفق قطبی (Aurora)** و **غروب پاستلی (Sunset)**.
- حالت‌های شبکه پس‌زمینه (نقطه‌ای، شبکه‌ای، بدون شبکه).
- قابلیت چسبیدن به شبکه (Snap to Grid) و نقشه کوچک کمکی (Minimap Radar).
- پشتیبانی کامل از کیبورد و کلیدهای میانبر استاندارد.

## 🛠️ فناوری‌های مورد استفاده (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons
- **Build Tool:** Vite
- **Backend & API:** Node.js, Express, WebSocket (`ws`)
- **Canvas Rendering:** Pure SVG & Vector Math (بدون وابستگی به کتابخانه‌های سنگین خارجی)
- **Storage:** Disk JSON persistence + Browser LocalStorage fallback

## 🚀 راهنمای نصب و راه‌اندازی (Getting Started)

### پیش‌نیازها
- **Node.js** نسخه 18 یا بالاتر
- **npm** یا **pnpm** یا **yarn**

### نصب وابستگی‌ها
```bash
npm install
```

### اجرای پروژه در محیط توسعه (Dev Mode)
```bash
npm run dev
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:3000` بروید.

### بیلد پروژه برای پروداکشن (Production Build)
```bash
npm run build
```

### اجرای نسخه پروداکشن
```bash
npm start
```
